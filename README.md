# Coach Logic Portfolio

A React + Tailwind CSS multi-page portfolio template for Coach Logic.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Routes

- `/` — cinematic introduction
- `/work` — selected work index
- `/work/:slug` — reusable project study page
- `/engineering` — systems and engineering practice
- `/about` — background and experience
- `/contact` — contact and access links
